Connect a Kraken sub-account

  1. On Kraken: create the sub-account and move into it only the money that strategy may trade. Keeping each live strategy on its own sub-account limits what any one model can lose.
  2. Create an API key in that sub-account with these permissions only: Query Funds, Query Open Orders & Trades, Query Closed Orders & Trades, Create & Modify Orders, and Cancel/Close Orders. Never tick Withdraw Funds.
  3. Add it here as a live account (form below). Use a short name such as kraken-trend.
  4. Put the key on the server, nowhere else. Sign in to the server over SSH, open /opt/sleeve-fund/kraken.env, and add the two lines this page shows for the account. Then run cd /opt/sleeve-fund && sudo docker compose up -d supervisor. Don't paste a key into GitHub, chat, or this dashboard.
  5. Check it here: within a minute the account shows the key as installed. Strategies can only use a live account once you've approved G2 and the server's live switch is on.
